# csv2hamlog - Turbo HAMLOG CSV インポート支援ツール

[![Platform](https://img.shields.io/badge/Platform-Windows%2010%20%2F%2011%20(64bit)-blue.svg)]()
[![License](https://img.shields.io/badge/License-Freeware-green.svg)]()

**`csv2hamlog`** は、アマチュア無線用ログ管理ソフト **Turbo HAMLOG/Win（ハムログ）** に、各種 CSV 形式の交信ログデータを直接かつ安全に一括インポートするためのデスクトップ支援ツール（フリーウェア）です。

WSJT-X / JTDX の FT8 ログ、Ctestwin などのコンテストログ、エクセル等で編集した日本語ヘッダー付き CSV など、多様なフォーマットを自動認識し、GUI のリアルタイムプレビュー画面で確認しながら Turbo HAMLOG に直接登録できます。

## ✨ 主な機能と特徴

1. **公式 `HAMLOG50.DLL` 連携による高信頼性**:
   - 独自のバイナリ書き換えではなく、浜田氏公式の `HAMLOG50.DLL` API（`HamlogOpen`, `THW_append`, `THW_flush`, `HamlogClose` 等）を経由して登録を行うため、インデックスファイル（`*.DX0` 〜 `*.DX4`）との整合性を保ったまま安全に追記されます。
   - 64bit Windows 環境でも動作するよう、専用の32bit連携ブリッジを内蔵しています。

2. **多様な CSV 形式の自動認識 & 正規化**:
   - **HAMLOG 標準 CSV**: バックアップやエクスポートされた CSV（Shift-JIS）
   - **WSJT-X / JTDX / FT8 形式**: `wsjtx_log.adi` 変換 CSV やエクスポート CSV（UTF-8）
   - **Ctestwin / zLog / コンテストログ形式**
   - **日本語ヘッダー形式**: 「コールサイン」「交信日」「時間」「周波数」「モード」など
   - 日付（`YYYY-MM-DD` / `YYYY/MM/DD` → `YY/MM/DD`）、時間（`HH:MM:SS` → `HH:MMJ` / `HH:MMU`）、周波数（Hz / kHz → MHz）を HAMLOG 仕様へ自動変換。

3. **直感的な列マッピング & リアルタイムプレビュー**:
   - ハムログ全14項目への列の割り当てを GUI のドロップダウンから自由に設定可能。
   - ドロップダウンには **CSV 1行目の実データ** が表示されるため、ヘッダーのない CSV でも迷わず設定可能。
   - 重複選択を自動防止するスマート排他制御付き。
   - 設定した列割り当てを **プリセットとして名前をつけて保存・読み込み** 可能。

4. **安全機能**:
   - **二重登録防止（重複チェック）**: 同一コール・同日・同バンド・同モードのQSOを自動検知してスキップ。
   - **自動バックアップ**: 登録直前にデータベースファイルを日時付きで自動バックアップ。
   - **二重起動警告**: Turbo HAMLOG 本体が起動中の場合に警告を表示。

5. **デスクトップ GUI **:
   - 初心者でも使いやすい直感的なデスクトップ画面。

## 💻 動作環境

- **OS**: Windows 10 / 11 (64bit)
- **対象ソフト**: Turbo HAMLOG/Win（Ver 5.0 以降を推奨）
- **前提条件**:
  - Turbo HAMLOG がインストールされており、**`HAMLOG50.DLL`** が存在すること（標準インストール先 `C:\Hamlog\Hamlog50.dll` 等）。
  - ※本ソフトウェアには `HAMLOG50.DLL` 本体は同梱されておりません。Turbo HAMLOG 本体のインストール環境が必要です。

## 🚀 使い方

1. **起動**:
   - [`csv2hamlog.exe`](file:///c:/Users/qqrp5/Documents/Python/csv-importer/csv2hamlog.exe) をダブルクリックして起動します。
2. **接続確認**:
   - 起動時に `HAMLOG50.DLL` と現在のデータベースパスが自動検出されます。
   - 「✔ Ver 5.xx」および「✔ レコード総数: ○○件」が表示されていることを確認してください。
   - ※検出されなかった場合や、別のサブログ等を指定したい場合は「参照...」ボタンから選択できます。
3. **CSV ファイルの選択**:
   - 「CSVファイル」の「参照...」をクリックし、インポートしたい CSV ファイルを選択します。
   - 「**プレビュー読み込み**」ボタンを押します。
4. **マッピング確認 & 調整**:
   - 画面中央のテーブルに変換プレビューが表示されます。
   - 必要に応じて「列マッピング設定」を開き、各項目が正しく対応しているか確認・変更してください。
5. **インポート実行**:
   - 内容を確認後、「**🚀 ターボハムログに登録 (インポート実行)**」ボタンをクリックします。
   - 自動バックアップが作成された後、データベースに追記登録されます。

## ❓ よくある質問 (FAQ) & トラブルシューティング

**Q. 「HAMLOG50.DLL が見つかりません」と表示される**  
A. Turbo HAMLOG が標準の `C:\Hamlog` 以外にインストールされている場合は、「参照...」ボタンから `Hamlog50.dll` を手動で選択してください。

**Q. 「Turbo HAMLOG が起動中です」と警告が出る**  
A. Turbo HAMLOG が起動した状態でデータベースを直接更新すると競合が発生する恐れがあります。安全のため、Turbo HAMLOG 本体を一度終了してからインポートを実行してください。

**Q. 文字化けして読み込まれる**  
A. CSV ファイルの文字コード選択欄で、「Shift-JIS (CP932)」または「UTF-8」を手動で切り替えて「プレビュー読み込み」を再度お試しください。

**Q. 「ブリッジプログラム不在」というエラーが出る**  
A. 本アプリと同じフォルダに `hamlog50_bridge.exe` が存在するかご確認ください。
